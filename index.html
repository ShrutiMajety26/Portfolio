Profile

Most of my work has been moving platforms that couldn't afford to break.

I'm a data engineer with 6+ years building large-scale ETL pipelines and cloud data platforms across Azure, AWS and Google Cloud. The through-line in my work is migration: legacy analytics platforms onto cloud infrastructure, on-prem distribution onto GCP, and most recently enterprise Marketplace commerce pipelines off deprecated Cosmos and SCOPE onto Azure Synapse Analytics — converting SCOPE scripts into Synapse SQL stored procedures and Mapping Data Flows while preserving complex business logic and derived flags.

That kind of cutover is mostly about what you don't break. I map upstream and downstream pipeline dependencies before touching anything, design parameterized and recursive ADF pipelines so ingestion is repeatable rather than hand-run, and build data quality checks into the path instead of bolting them on afterwards. I've also contributed to threat model reviews and applied secure practices — Key Vault secret management, least-privilege Service Principal and Managed Identity access.

Day to day I work in Apache Spark, PySpark, Databricks, Azure Data Factory and Synapse, with growing depth in Lakehouse architecture, data governance and BI reporting. I'm an AWS Certified Cloud Practitioner, and I use AI-assisted tooling — GitHub Copilot, Claude in VS Code, Databricks Assistant, Microsoft Fabric Copilot — as part of how I ship.
